# voidra-skills documentation

This repository keeps reusable agent skills together while allowing users to install each one independently. Skill content lives in `skills/`; root tooling validates and publishes it.

- [Skills and authoring](skills.md): package layout, the `init` skill, and adding new skills.
- [Development](development.md): prerequisites, commands, validation, and tests.
- [Publishing](publishing.md): first-time GitHub setup, single-skill publishing, and skills.sh discovery.

See the [repository overview](../README.md) and [project instructions](../AGENTS.md).
