# Accessibility evidence

Read only for the related operation in the parent skill. This is a scoped, self-contained
summary of the locally maintained `eai-accessibility` responsibility, not that skill's entrypoint
or permission to invoke it. Parent snapshot restrictions and project authority apply.

Use native semantic controls and meaningful accessible names, labels, focus behavior and keyboard interaction. Verify contrast, target sizing, motion preferences and screen-reader behavior against the project's applicable platform/standard and actual rendered output. Automated checks complement manual interaction; passing a scan alone does not establish accessibility conformance. Preserve scoped WCAG/native-platform requirements instead of imposing web ARIA on every platform.
