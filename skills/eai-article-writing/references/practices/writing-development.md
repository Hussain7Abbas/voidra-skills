# Developing long-form writing

Use this optional mode only when raw ideas need development or readers lack prerequisites.
A clear drafting/editing request can proceed directly without another interview.

For exploration, collect promising fragments from supplied notes or conversation before
forcing an outline. Preserve the author's original material. For shaping, establish the
audience's existing knowledge and the argument's purpose; introduce a concept before a
later block relies on it. Use one job per paragraph/section and remove unsupported leaps.
An example-first opening is useful when intelligible to that audience, not a universal rule.

Offer alternative openings or narrative directions only where they help a real choice.
Block-by-block approval is an opt-in collaborative mode; ordinary drafting should deliver
a coherent whole. Preserve user edits and separate raw notes from a finished draft only
when authorized storage makes that useful. Keep factual claims traceable and voice matched
to supplied/confirmed examples. This reference does not invoke a brand skill.

References: [audience](https://developers.google.com/tech-writing/one/audience),
[paragraphs](https://developers.google.com/tech-writing/one/paragraphs).
