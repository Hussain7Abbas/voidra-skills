# Research routing

Read only for the related operation in the parent skill. This is a scoped, self-contained
summary of the locally maintained `eai-research-ops` responsibility, not that skill's entrypoint
or permission to invoke it. Parent snapshot restrictions and project authority apply.

Start from supplied evidence and the question. Use the lightest current primary-source investigation that resolves the uncertainty. Distinguish facts, user context, inference, recommendation and freshness. Use actual available search/browsing/connectors, not assumed tools. Another explicitly selected research workflow is optional; do not automatically chain skills, persist notes, create monitors or contact people.
