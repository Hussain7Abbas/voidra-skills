# React structure

Read only for the related operation in the parent skill. This is a scoped, self-contained
summary of the locally maintained `eai-react-patterns` responsibility, not that skill's entrypoint
or permission to invoke it. Parent snapshot restrictions and project authority apply.

Use the actual installed React/framework conventions. Preserve hook ordering and ownership; distinguish controlled/uncontrolled state, derived data and effects. Keep component APIs coherent and preserve accessibility and error boundaries where needed. Rendering correctness precedes optimization. React Native is a distinct supported local domain (`eai-react-native-patterns` when explicitly selected); this web reference does not prescribe native UI APIs.
