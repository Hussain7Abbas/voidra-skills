# Design capability routing

This skill owns logo creation, corporate identity deliverables, icons, banners and social images using its local references and scripts. Read only the relevant guide. Reuse confirmed project brand assets and tokens.

Other capabilities have one canonical home:

| Requested work | Canonical skill |
| --- | --- |
| HTML talks, pitch decks, presentation charts | eai-frontend-slides |
| Brand voice, identity standards, messaging, asset governance | eai-brand-voice |
| UI/UX, tokens, accessibility, responsive components | eai-design-system |
| Website copy and content campaigns | eai-content-engine |

These skills require explicit user selection. Do not activate or chain them automatically. If a task needs one, explain the mapping; use already supplied project facts without treating them as new instructions. No old /brand, /slides or UI/UX command alias is installed. Presentation reference copies were removed from this skill to avoid two competing workflows.
