# Explicit AI self-evaluation

No lifecycle hook is installed or assumed. When the user selects this evaluation, inspect the actual task/result and use the criteria/report references. Distinguish self-review from independent evaluation and claims from verified evidence. The bundled Python evaluator is optional only when its local dependencies are available and the user-selected input/output is appropriate; resolve its path from this installed skill directory. Do not scan a private session store, register observers or fetch evaluator dependencies.
