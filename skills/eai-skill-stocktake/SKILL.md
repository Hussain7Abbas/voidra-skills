# AI Skill Stocktake

Inventory only the requested current host's skill roots, normally user .agents/skills and project .agents/skills. Resolve links carefully, deduplicate by canonical path and report which locations were actually inspected. Read skill metadata and relevant instructions/resources; do not treat a passing directory inventory as functional validation.

Evaluate actual capability, scoped description, instruction conflicts, source attribution, missing dependencies, host-specific assumptions, dangerous side effects, reference quality and overlap with other installed skills. Separate compatible instruction-only guidance from conditional integrations and disabled runtime paths. Usage history is unknown unless a specific authorized data source provides it; do not infer use frequency from file age or scrape sessions.

Return a table keyed by real path with retain, improve, consolidate or retire recommendations, evidence and a specific proposed change. Work inline unless an independent audit is explicitly authorized and supported. Cache a result only when a durable report was requested; no cache is needed to complete an audit. Archival/deletion/renaming requires actual user authorization and a recoverable operation. Verify discovery/references after any authorized consolidation.

For the optional local skill inventory helper, explicitly set SKILL_STOCKTAKE_GLOBAL_DIR and SKILL_STOCKTAKE_PROJECT_DIR (or pass the project root argument).
