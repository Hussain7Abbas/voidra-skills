# AI Plan Routing

This is a generative planning operation. Read the supplied plan and requested step/range; do not execute implementation or shell commands. Preserve the plan's IDs, dependencies, exclusions and acceptance criteria. If the source is missing or ambiguous, identify the missing prerequisite rather than inventing a step.

Classify each selected step as feature, change, defect, refactor, tests, documentation, research or review. Return a dependency-ordered overview and a self-contained AI assistant prompt for each step. Each prompt includes `[Plan: <path>#step-<id>]`, objective, bounded scope, required context/inputs, expected deliverable, observable acceptance and necessary exclusions. Carry the actual task in the prompt; a bare skill name never substitutes for its scope.

Use ordinary AI task text, not plugin slash commands or invented flags. An explicitly requested skill may be included using its real installed eai-prefixed name; do not activate skills while generating prompts. Steps requiring missing information, tools or authorization are marked blocked with the exact prerequisite. For a very large plan, provide an overview and ask for the next bounded range. Report every selected step and do not imply that work ran or that approval was granted.
