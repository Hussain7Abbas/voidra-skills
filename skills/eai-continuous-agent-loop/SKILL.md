# Continuous Agent Loop

This is the v1.8+ canonical loop skill name. It supersedes `eai-autonomous-loops` while keeping compatibility for one release.

## Loop Selection Flow

```text
Start
  |
  +-- Need strict CI/PR control? -- yes --> continuous-pr
  |
  +-- Need RFC decomposition? -- yes --> rfc-dag
  |
  +-- Need exploratory parallel generation? -- yes --> infinite
  |
  +-- default --> sequential
```

## Combined Pattern

Recommended production stack:
1. RFC decomposition (`eai-ralphinho-rfc-pipeline`)
2. quality gates (`eai-plankton-code-quality` + project quality check)
3. eval loop (`eai-eval-harness`)
4. session persistence (`eai-nanoclaw-repl`)

## Failure Modes

- loop churn without measurable progress
- repeated retries with same root cause
- merge queue stalls
- cost drift from unbounded escalation

## Recovery

- freeze loop
- run workflow audit
- reduce scope to failing unit
- replay with explicit acceptance criteria
