## Local snapshot policy

- This policy is behavioral guidance, not an OS sandbox or a guarantee of safety. Use host permissions/isolation when running code or processing untrusted media.

# AI Configuration Cleanup

Read only the user-selected configuration/skill/project surfaces. Inventory duplicate names, broken links, missing resources, obsolete instructions and demonstrably unused artifacts. File age or size alone does not establish that a skill is safe to remove; do not inspect credentials or unrelated chat/session stores.

For each candidate record its path, evidence, proposed action, impact and recovery method. Preserve attribution, user customizations, managed/system skills and the collection's explicit-only policy. Group recommendations by consequence so the user can review concrete changes.

Apply cleanup only when the user's request covers the named items. Back up displaced content outside skill discovery, unlink a symlink rather than deleting its target and never follow a path outside the authorized root. Avoid permanent deletion when a reversible move satisfies the request. Verify the remaining skill links and related references; report exact changes and recovery location. This is a manual audit, not a background garbage collector or a hook-based enforcement mechanism.
