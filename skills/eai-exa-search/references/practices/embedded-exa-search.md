Read only for the related operation in the parent skill. This is a scoped, self-contained
summary of the locally maintained `eai-exa-search` responsibility, not that skill's entrypoint
or permission to invoke it. Parent snapshot restrictions and project authority apply.

Inspect exposed tool schemas and verify current capabilities rather than inventing names, quotas or response shapes. Built-in browsing can answer factual questions when that connector is unavailable.
